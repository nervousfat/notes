# 编辑与修订时间

`updateNote(note, patch, now)` 只更新明确提供的 title、content、tags 和 pinned 字段，保留 id 与 createdAt。`togglePin` 切换置顶状态并复制标签数组。两种操作均返回新笔记，不直接修改传入对象。

每次修改的 updatedAt 必须比前一版本更晚。通常使用当前系统时间；当时钟回拨、连续操作落在同一毫秒或导入了将来的修订时间时，使用前次更新时间加 1 毫秒，并保证不早于创建时间。这样编辑后的记录仍能按时间比较和备份。

这是一项本地版本排序规则，不证明设备时钟准确。导入了未来时间的笔记可能继续显示未来修订日期，但原始创建日期会保留。不要批量改写创建日期来掩盖时钟问题。

显式 now 参数必须是带毫秒的标准 ISO 字符串。非法时间或超过 Date 可表示范围会抛错，原笔记保持不变。`tests/revision-clock.test.js` 覆盖正常前进、相同时刻、回拨及最大时间边界。

删除使用 id 查找，只移除匹配项；找不到 id 时返回新数组而不报错。调用方可据此容忍已经删除的记录，但仍应向使用者明确反馈当前状态。
