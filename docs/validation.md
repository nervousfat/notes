# 验证与恢复

运行 `npm test` 自动发现原有 `core.test.js` 与新增 `tests/*.test.js`；运行 `npm run check` 检查语法。单元测试只使用内存数据，不联网、不读取私人笔记，也不需要安装第三方库。

专题测试覆盖规范化幂等性、创建边界、时间回拨、搜索交集、排序并列、多语言统计、Markdown 块切换、严格模型、UTF-8 容量、合并性质、笔记本容量、文件名、示例隔离和恢复矩阵。失败时先定位对应文件，再运行完整测试验证关联行为。

`recoverNotebook` 区分三种状态：没有存储值时生成独立示例并标记 fresh；合法空备份恢复为空且不重新生成示例；损坏或不支持的文本保留原始 raw，并返回错误与空集合。空字符串属于损坏数据，不能当作首次使用。

恢复函数不会写存储。调用方遇到错误时应暂停自动覆盖，先允许下载原始内容。后续导入完整验证过的备份、确认保留所需内容后，才重新启用持久化。

浏览器验证另需检查自动保存、切换笔记、手动保存快捷键、配额不足、跨窗口冲突和下载行为。这些不属于领域单元测试；不要仅凭单元测试通过就声称浏览器持久化完全可靠。
