# JSON 备份格式

备份是版本化 JSON 对象，包含 version、exportedAt 和 notes。version 必须为 1，notes 是完整笔记数组。exportedAt 记录导出时刻，不用于决定哪篇笔记较新；笔记自己的 updatedAt 才是版本依据。

```json
{
  "version": 1,
  "exportedAt": "2025-06-01T10:00:00.000Z",
  "notes": []
}
```

笔记需包含 [数据模型](note-model.md) 中的七个字段，id 最多 128 个 UTF-16 单元。备份验证严格拒绝超长字段、非法日期、重复 id 和更新时间早于创建时间。未知额外字段不参与恢复。

文件最多 5,000,000 个 UTF-8 字节，包含 JSON 格式和空白，最多 1,000 篇笔记。两个限制必须同时满足。中文和 emoji 占多个字节，字符数少于五百万并不保证文件小于 5 MB。

序列化会执行与导入一致的完整验证。成功导出的文本可通过核心导入；超限会明确失败，不截断正文、不删除笔记。大笔记本应先导出部分集合并清晰标记范围，不要通过裁剪 JSON 文本强行缩小文件。

解析只返回新的、完整验证过的笔记数组。调用方应在成功后再更新持久化状态，失败时保留原数据与备份文件。
