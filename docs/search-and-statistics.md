# 查找、排序与统计

搜索按空白分成多个关键词，忽略大小写；所有词都必须在同一篇笔记的标题、正文或标签中出现。不同词可以命中不同字段。标点按普通文本处理，不解释正则表达式。标签筛选使用完整标签，work 不等于 workshop，并可以与“只看置顶”叠加。

所有排序模式都优先显示置顶笔记。newest 按更新时间倒序，oldest 按更新时间正序，同一时刻按 id 排序。title 按中文区域的标题排序。排序返回新数组，不改变输入集合。

字数统计将每个汉字（包括 Unicode 扩展汉字）计为一个词，其他语言按字母/数字组成的词组计数。单词内部的直引号、弯引号或连字符允许连接。emoji 不计入词数，但计入字符数；空白不计入字符数。

字符数使用 Unicode 码点计数，不等于可见字形数量，也不等于字段限制使用的 UTF-16 长度。组合字符和复合 emoji 可能由多个码点组成。统计适合写作参考，不用于计算文件大小。

全笔记统计汇总正文词数与字符数，标签数按整个笔记本去重，另给出笔记总数和置顶数。测试入口为 search-intersections、ordering-ties 和 multilingual-statistics 三个文件。
