# 笔记模型

一篇笔记包含 id、title、content、tags、pinned、createdAt 和 updatedAt。id 标识同一篇笔记的不同版本，不应在每次编辑时更换。

`createNote(values, now)` 默认生成 id 和当前标准 ISO 时间，创建时间与更新时间初始相同。空白标题使用“未命名笔记”，正文默认为空，标签为空数组，置顶默认为 false。调用方需要可重复结果时，应显式提供 id 和 now。

交互创建会把标题限制为 120 个 UTF-16 单元，正文限制为 200,000 个单元；标签使用 [标签规范](tags.md)。超过长度的交互输入会截断，因此批量迁移时应先检查长度，不能用此函数替代严格备份验证。

正文保存原始 Markdown 文本，不在数据模型中保存预览 HTML。每次创建生成独立的标签数组，修改一篇笔记不会改变另一篇的默认状态。

日期表示精确时刻，使用带毫秒的标准 UTC ISO 字符串，例如 2025-06-01T10:00:00.000Z。展示时可以转换为当地时间，数据层应保留完整时间字符串。
