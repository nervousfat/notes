# Markdown 支持范围

预览支持一至三级标题、使用 - 或 * 的无序列表、单行引用、分隔线、三反引号围栏代码块，以及行内粗体、斜体、反引号代码和链接。代码围栏后的语言名不会触发语法高亮。

每个普通非空文本行渲染为一个段落，连续引用不会合并成复杂引用结构。列表不是嵌套列表解析器，四级及更深标题保留为普通文本。表格、任务复选框、图片、脚注、有序列表与完整 CommonMark 嵌套语法不属于已实现功能。

CRLF、CR 和 LF 会归一化，便于在 Windows 与其他系统之间交换文件。未关闭的代码围栏会把剩余文本当作代码显示，不会丢弃尾部内容。

原始 HTML 按文本展示。链接只支持明确的 http、https 和 mailto 协议，预览不会获取远程图片或执行文档中的脚本。点击网页链接仍会离开本地环境并访问目标网站。

需要在其他 Markdown 编辑器分享时，请同时保留原始导出文件。不同渲染器支持范围不同，同一正文的排版可能变化，正文原文不会因此改变。
