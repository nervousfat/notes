# 标签规范

标签输入可以是数组，或使用英文/中文逗号分隔的字符串。每项去除首尾空白、转换为小写，再限制为 32 个 UTF-16 单元。规范化后重复的标签只保留第一次，最多保留 12 个不同标签。

例如 `Work, work，生活` 得到 work 和 生活。重复项不会占用额外名额；两个长标签如果前 32 个单元相同，会归并为一个。标签内部空格保留，不会被拆成多个标签。

建议使用短而稳定的主题名，避免只在截断部分区分分类。UTF-16 单元不是可见字数，部分 emoji 占两个单元；当前限制以 JavaScript 字符串长度为准。

`normalizeTags` 返回新数组，反复规范化不会继续改变结果。验证命令为 `node --test tests/tag-properties.test.js`。备份验证比交互输入更严格，不能依赖自动截断来修复任意不符合格式的备份。
